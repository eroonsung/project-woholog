# device_check.md: 8.5단계 실제 기기 점검·지인 테스트 (D-117)

8단계(체크리스트)가 끝난 뒤, 9단계로 가기 전에 한다. 운영 주소 https://project-woholog.vercel.app 에서 Yvonne가 직접 하고, 나온 문제를 고친 뒤 9단계로 간다.
**테스트로 저장된 결과(`/r/…`)의 id는 맨 아래 칸에 적고 `docs/ops/test_data.md`로 옮긴다**(오픈 전 일괄 삭제 대상).

## 1. 기기·환경 (아래 4곳을 모두)
| # | 환경 | 하는 법 | 확인 |
|---|---|---|---|
| E1 | 내 휴대폰 기본 브라우저 (Safari/Chrome) | 주소 직접 입력 | [ ] |
| E2 | 카카오톡 링크로 열기 | 나에게 보내기 채팅에 링크를 보내고 눌러서 열기 | [ ] |
| E3 | 인스타그램 앱 안 브라우저 | DM·스토리·프로필 링크로 열기 | [ ] |
| E4 | PC 크롬 | 창 폭을 1280px / 1024px / 800px로 바꿔 보기 | [ ] |

## 2. 흐름 (각 환경에서 가능한 만큼. E1·E2·E3은 끝까지)
1. [ ] 홈 `/` → "내 나라 확인하기"
2. [ ] 테스트 12문항 (Q1~Q12). 중간에 새로고침·뒤로 가기, 나이 36세 안내(Q2), 이어서 하기
3. [ ] 결과 `/r/…` (카드·조건 줄·현실 미리보기·TOP 3·"이렇게 바꾸면")
4. [ ] 비교 (결과의 "나란히 비교" → `/r/…/compare`, 나라 추가·빼기)
5. [ ] 나라 상세 `/countries/JP` (목차·여행경보·필수 앱·추천 준비물) + 29개국 비교표 정렬·필터
6. [ ] 체크리스트 `/checklist?c=JP`: 출국일 고르기 → 체크 → **새로고침** → **링크 복사** → **다른 브라우저(또는 다른 기기)에서 열기** → 체크가 그대로 옮겨졌는지
