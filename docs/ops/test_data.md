## 그 밖의 표
- `rate_limits`: 요청 제한 기록(IP 해시). 24시간이 지나면 다음 요청 때 자동으로 지워져서 따로 기록하지 않는다.
- `launch_subscribers`, `user_reports`, `feature_votes`: 테스트로 넣은 것이 있으면 여기에 적는다(지금은 없음).
