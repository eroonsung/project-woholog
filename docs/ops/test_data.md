> 내가 만든 자동 확인 스크립트는 이제 `/api/result` 요청을 가짜 응답으로 막아 운영 DB에 저장하지 않는다(질문 12개를 끝까지 도는 확인 포함). 운영에 실제로 저장되는 확인은 일부러 한 번만 하고 여기에 적는다.

## 그 밖의 표
- `events`(이용 이벤트, 마이그레이션 008 적용 뒤 생김, D-137): 오픈 전에 쌓인 행은 모두 테스트·점검 이벤트라 **오픈 직전에 전체를 비운다**(`delete from events;`, 허락 후). id를 따로 기록하지 않는다.
- `rate_limits`: 요청 제한 기록(IP 해시). 24시간이 지나면 다음 요청 때 자동으로 지워져서 따로 기록하지 않는다.
