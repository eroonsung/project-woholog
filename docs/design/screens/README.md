# screens/

예비용 와이어프레임 PNG. 기준은 Figma 파일 [Woholog-Wireframe](https://www.figma.com/design/hcE2mDdgJdsBqM2GPydP0L/Woholog-Wireframe)이다.

- 파일 이름 = Figma 프레임 이름 (`S07_result_m.png`, `S07_result_w.png`)
- 만드는 법: Figma에서 `Mobile`·`Web` 페이지의 프레임을 모두 선택 → 오른쪽 Export에서 PNG 1x → 이 폴더에 저장
- Figma를 고치면 바뀐 프레임만 다시 내보낸다
