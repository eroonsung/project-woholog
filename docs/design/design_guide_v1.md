# 워홀로그 디자인 가이드 v1 (2026-11-05)

방향: 연한 아쿠아 + 코랄(보색). 흰 배경 기반. 목업은 항상 웹 + 모바일 둘 다.

## 컬러
- Aqua #9FE6F3 (메인 배경 블록·히어로) / Aqua 50 #EAF9FC / Aqua 100 #D6F5FB / Aqua Dark #086A7D (링크·강조 글씨, 11단계에서 #0A7A8F → #086A7D, D-133)
- Coral #FF7E5F (화면당 주요 행동 버튼 1개, 글씨는 네이비) / Hover #F26A4A / Coral 50 #FFE6DF / Coral Dark #B9432A
- Navy #1D3366 (글씨·로고·보조 버튼)
- Lime #ABE54C (스티커·뱃지·공유 카드에서만) / Lime 50 #EEF9DC / Lime Dark #4C7514
- Gray: Text2 #5A6684, Text3 #65708C(11단계에서 #8A93A8 → #65708C, 흰색 위 4.9:1),  Line #E6E9EF, BG Subtle #F6F8FA, White #FFFFFF, Error #E5484D
- 대비: 네이비 on 아쿠아 8.8:1, 네이비 on 코랄 약 4.9:1, 진한 아쿠아 on 흰색 6.2:1(Aqua 100 위 5.4:1). 흰 글씨 on 코랄·연한 아쿠아 글씨는 금지
- 배민 민트(#2AC1BC)와 겹치지 않게 민트 대신 아쿠아 채택. 누런 오프화이트는 사용자 비선호

## 폰트
- Pretendard 단일 (무료, SIL OFL). 굵기 400/500/700/800/900. 대체: SUIT, Noto Sans KR

## 글자 크기 (웹 / 모바일, 굵기, 줄간격)
- Display 56 / 36, 900, 1.12, 자간 -3%
- H1 40 / 30, 800, 1.2 · H2 28 / 22, 800, 1.3 · H3 20 / 18, 700, 1.4
- Body L 18 / 16, 500, 1.6 · Body 16 / 15, 400, 1.6 · Caption 13 / 12, 500 · Button 16, 800
- 최소 12px

## 간격·모서리·그림자
- 4의 배수: 4, 8, 12, 16, 24, 32, 48, 64
- 모서리: 칩 8 · 버튼·입력 14 · 카드 20(웹 큰 카드 24) · 알약 999
- 그림자: 카드 0 6px 18px rgba(29,51,102,.10) / 떠 있는 카드 0 12px 28px rgba(29,51,102,.14)

## 레이아웃
- 웹: 기준 1440, 콘텐츠 최대 1120, 좌우 40, 12칸·간격 24, 섹션 간격 96
- 모바일: 기준 375, 좌우 20, 4칸·간격 16, 섹션 간격 56
- 기준점: 1024↑ 웹, 768~1023 태블릿, 767↓ 모바일
- 버튼 높이: 웹 52 / 모바일 48(가로 꽉), 터치 영역 최소 44

## 아이콘
- Lucide 또는 Tabler (선 1.75~2px). 국기는 이모지 대신 아이콘 세트 추천(윈도우 호환)

## 색 적용 규칙 (v1.1 추가, 2026-11-10 · 11/6 From/To 시안 기준)
| 요소 | 적용 |
|---|---|
| 페이지 배경 | 흰색 #FFFFFF. 헤더도 흰색 + 아래 1px Line |
| 히어로 | 화면 너비 꽉 찬 아쿠아 #9FE6F3 단색 블록(모서리 없음, 그라데이션 없음). 제목 네이비, 본문 #2E4470 (네이비 80% 톤, 히어로 본문 전용) |
| 주요 버튼 | 코랄 배경 + 네이비 글씨(800~900), 모서리 14, 그림자 0 6px 14px rgba(255,126,95,.35). 화면당 1개 |
| 보조 버튼 | 네이비 배경 알약 + 흰 글씨(예: 헤더 "시작하기"), 또는 밑줄 친 네이비 글자 링크 |
| 전환 버튼(From/To) | 바탕 BG Subtle, 선택된 쪽 네이비 배경 + 흰 글씨, 나머지 Text2 |
| 히어로 위 작은 라벨 | 흰 알약 + 진한 아쿠아 글씨 |
| 태그·선택 상태 | Aqua 100 배경 + 진한 아쿠아 글씨/테두리 1.5px |
| 스티커 | 라임 원형, 12° 기울임, 네이비 글씨. 화면당 1개 |
| 카드 | 아쿠아 위에 뜬 카드: 흰색, 모서리 22, 떠 있는 카드 그림자. 흰 섹션 안 카드: BG Subtle 배경, 모서리 18, 그림자 없음 |
| 입력칸 | 흰색, 테두리 1.5px Line, 모서리 14. 포커스 시 진한 아쿠아 테두리 + 3px Aqua 100 링 |
| 섹션·안내 배경 | Aqua 50 |
| 단계 번호 원 | 아쿠아 배경 + 네이비 숫자 |
| 모달 | 뒤 배경 rgba(29,51,102,.45), 모서리 24 |
| 적합도 표시 | ✓ Aqua 100 원 + 진한 아쿠아 / △ Coral 50 원 + Coral Dark / ✗ BG Subtle 원 + Text3. ✗에 빨간색(Error) 쓰지 않기 |
| 주의 뱃지(추첨·안전 주의) | Coral 50 배경 + Coral Dark 글씨 |
| 완료 뱃지 | Lime 50 배경 + Lime Dark 글씨 |
