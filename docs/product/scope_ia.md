# 워홀로그 기능 범위·메뉴 구조 v1.1 (2026-11-10)

결정 (11/10): MVP = **적합도 테스트 + 29개국 비교표 + 나라 상세 + D-day 체크리스트**. To Korea는 **영어 대기자 모집 페이지 1장**만.
추가 결정 (11/10): **기획서의 나머지 기능도 모두 메뉴와 화면에 넣는다.** 내용이 없는 기능은 "준비 중" 화면으로 열고, "원해요" 투표와 오픈 알림 신청을 받아 다음에 만들 기능을 고르는 데 쓴다.
목표: 12/31 오픈 → 1/31까지 월 방문 3,000 · 체크리스트 시작 100명.

## 2. 메뉴 구조 (사이트맵)
메뉴는 워홀 여정 순서(나라 고르기 → 준비하기 → 현지 생활 → 귀국)로 묶는다. **Soon** 뱃지가 붙은 항목은 `/soon/[slug]` 준비 중 화면으로 간다.

```
헤더 (웹)
로고 | From/To 전환 | 나라 고르기 ▾ | 준비하기 ▾ | 현지 생활 ▾ | 귀국 ▾ | 커뮤니티 Soon | 로그인 · 시작하기(Soon 모달)

나라 고르기 ▾
  ├─ 나라 추천 테스트 → /test
  ├─ 29개국 비교 → /countries
  └─ 가이드 → /guides
준비하기 ▾
  ├─ D-day 체크리스트 → /checklist
  ├─ 나라별 필수 앱 → /countries/[code]#apps (나라 고르는 창)
  ├─ 초기 비용 계산기 Soon → /soon/cost-calculator
  ├─ 예산 저축 플래너 Soon → /soon/savings-planner
  ├─ 모집 오픈 알림 Soon → /soon/intake-alerts
  └─ 나라별 정착 가이드북 Soon → /soon/guidebook
현지 생활 ▾
  ├─ 일자리 찾기 가이드 Soon → /soon/job-guide
  ├─ 세컨비자 조건 트래커 Soon → /soon/second-visa
  ├─ 환율·송금 알림 Soon → /soon/fx-alerts
  ├─ 안전 체크인 Soon → /soon/safety-checkin
  └─ 출국 동기 찾기 Soon → /soon/departure-buddies
귀국 ▾
  ├─ 세금·연금 환급 도우미 Soon → /soon/tax-refund
  ├─ 워홀 결산 리포트·뱃지 Soon → /soon/year-report
  └─ 경험을 이력서로 Soon → /soon/resume
커뮤니티 Soon → /soon/community (Q&A·후기, 경험자 1:1 상담, 언어 교환 소개)
푸터: 곧 나올 기능 전체 보기(/soon) · 처리방침 · 정보 제보 · 면책 문구
```

화면 사이 이동
- 결과 → 나라 상세, 이 나라로 준비 시작(체크리스트), 공유 이미지 저장
- 나라 상세 → 내 적합도 확인, 비교에 담기, 체크리스트 만들기, 필수 앱, 추천 준비물
- 체크리스트 "출국 1주 전" → 필수 앱, 추천 준비물
- 준비 중 화면 → 원해요, 오픈 알림 신청, 지금 쓸 수 있는 비슷한 기능으로 가기

모바일 메뉴
- 헤더: 로고 + From/To 전환 + 햄버거
- 햄버거: 단계별 접기·펼치기(나라 고르기 / 준비하기 / 현지 생활 / 귀국 / 커뮤니티), Soon 뱃지 표시, 맨 아래 "내 나라 확인하기" 버튼
- 하단 탭 바는 쓰지 않음

## 4. 추천 준비물 (제휴 자리)
- 위치: 나라 상세 "생활 정보" 아래, 체크리스트 "출국 1주 전" 단계.
- 칸: eSIM · 여행자 보험 · 해외 송금 · 항공권. `content/partners.json`에 `{category, name, url, disclosure}`.
- 링크가 없으면 "추천 준비물을 고르는 중이에요" 카드만 보여 준다.
- 링크가 있으면 카드에 **"광고" 또는 "제휴 링크" 표시를 반드시** 넣고, 아래에 "이 링크로 구매하면 워홀로그가 수수료를 받을 수 있어요. 가격은 같아요." 문구를 단다(공정위 추천·보증 심사지침).

## 6. 체크리스트 MVP 규칙
- 시작: 나라 1곳 + 출국 예정일(모르면 "아직 몰라요" → D-day 없이 단계만 표시).
- 단계: 결정(decide) → 신청(apply) → 출국 준비(prepare) → 출국(depart) → 도착 후(arrive). `checklist_items.phase` 그대로.
- 항목 = 공통 항목(`program_id` 없음) + 그 나라 항목 + 그 나라 서류(`required_documents`, 발급 후 유효 기간·번역·아포스티유 표시).
- 날짜: 출국일 + `days_offset`. 지난 항목은 빨간색 대신 "늦었어요" 회색 표시.
- 저장: 체크 상태는 브라우저(localStorage)에만. 다른 기기로 옮기려면 "내 체크리스트 링크" 복사(체크 상태를 링크에 담음, 서버 저장 없음).
- 측정: 첫 체크를 하면 "체크리스트 시작" 이벤트 1회.
- **내용이 아직 없음**: 공통 항목 약 25개 + 5개국(호주·일본·캐나다·영국·뉴질랜드) 서류부터 작성 필요.
