# checklist_v1.md: 체크리스트 내용 v1 (2026-11-11)

검토용 문서다. DB에는 `supabase/seed/seed_checklist_v1.sql`로 넣는다. 둘을 같이 고친다.

- D-day: 출국일 기준 (D-90 = 출국 90일 전, D+7 = 도착 7일 뒤)
- ⚠ = `needs_review`. 공식 페이지로 아직 확인하지 못한 값이다. **오픈 전에 원문으로 확인**하고 false로 바꾼다.

## 4. 오픈 전에 확인할 것
- 호주: 공식 페이지(Home Affairs 417)에서 서류·신체검사·잔고 기준. 지금은 상업 블로그 출처뿐이다.
- 일본: 주한 일본대사관 공지 원문으로 서류 목록과 잔고증명 발급일 기준. 지금은 인포센터 + 상업 블로그.
- 영국: 한국이 결핵 검사 대상 나라인지 (gov.uk/tb-test-visa).
- 뉴질랜드: 한국이 결핵 저위험 나라인지(흉부 X-ray 필요 여부), 보험 의무 문구 (immigration.govt.nz Korea Working Holiday Visa).
- 공통: 병역 국외여행허가 기준 나이, 건강보험 급여정지·면제 기준 (병무청·국민건강보험공단).
